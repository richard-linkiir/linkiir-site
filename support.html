In scope & out of scope

Support for the integration layer.

In scope

  • Second-line incidents and break-fix for existing integrations
  • HL7, X12, XML, REST and custom integration flows
  • New integration design, build and test assistance where included by tier
  • Channel inventory, message flows, runbooks and handover documentation
  • Migration guidance for Iguana, Rhapsody, Mirth, Cloverleaf and BizTalk estates
  • High-availability architecture support for Professional and Enterprise plans

Out of scope (by default)

  • End-user help desk for clinicians, schedulers or front-office staff
  • EHR application support outside the interface layer
  • Network, firewall and infrastructure operations outside integration responsibilities
  • Custom application development unrelated to integration
  • Database administration unrelated to supported integration engines
  • Hardware procurement and on-site break-fix

Additional scope can be added in an Order Form or handled as a separate engagement.
